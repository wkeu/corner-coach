# Corner Coach — 2010 Peugeot 308

A standalone browser-based reversing-around-a-corner practice game for the Irish driving test. Includes variable road geometry, user-selected turn-in points with early/late feedback, the metallic-blue 2010 Peugeot 308, steering-wheel indicator, adaptive projected reversing path, and an adjustable left-side mirror.

## Play online

After GitHub Pages is enabled: **https://wkeu.github.io/corner-coach/**

## Publish through GitHub Pages

1. Upload the three files in this folder to the `main` branch of the [`wkeu/corner-coach`](https://github.com/wkeu/corner-coach) repository. `index.html` must be in the repository root.
2. In GitHub, open **Settings → Pages → Build and deployment**.
3. Set **Source: Deploy from a branch**, **Branch: main**, **Folder: /(root)**, and save.
4. Open **https://wkeu.github.io/corner-coach/** once the deployment completes.

## Notes

This is a simplified teaching aid, not a real-world vehicle simulator. Mirror geometry and steering reference points are approximations, not instructions for driving without observation or a qualified instructor. No dependencies, logins or internet connection required to play the downloaded HTML file.
